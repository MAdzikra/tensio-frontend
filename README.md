# TENSIO — Frontend

Frontend aplikasi **TENSIO**, sistem screening risiko hipertensi berbasis web yang dikembangkan untuk membantu pengguna melakukan screening awal berdasarkan faktor-faktor risiko hipertensi.

## 🚀 Overview

TENSIO menyediakan antarmuka bagi pengguna untuk mengisi data screening dan memperoleh hasil prediksi risiko hipertensi yang diproses oleh backend menggunakan model Machine Learning.

Frontend dibangun menggunakan **React** dan **Tailwind CSS**, serta berkomunikasi dengan backend melalui REST API.

## ✨ Features

* 📝 Form screening risiko hipertensi
* 🤖 Menampilkan hasil prediksi risiko
* 📊 Penyajian hasil screening secara informatif
* 📱 Responsive design
* 🔗 Integrasi dengan REST API
* 🎨 Modern UI menggunakan Tailwind CSS

## 🛠️ Tech Stack
